02 · how it works

Three stages, mandatory human gates

Every feature ships through a spec-driven pipeline. Specialized subagents own each phase, state lives as files, and you stay in control at every gate.

Specialized subagents

One agent per phase — architect designs, implementer codes, tester writes tests, qa validates, security audits, delivery ships. No generalist trying everything.

Mandatory human gates

You approve the plan before any code is written, and the push before any PR opens. Autonomous mode skips per-PR stops but never these two.

State as files, not memory

Every feature opens session-docs/{name}/. Any Claude session resumes cold — across compactions, sessions, and machines.

// what's inside

Shared knowledge graph

One graph per team. Every agent reads and writes the same memory — sessions, refactors, and PRs leave a trail the next agent can find.

Semantic search

384-dim embeddings indexed with pgvector HNSW. search_nodes("auth patterns") returns what you mean, not just substring hits.

Three-layer filter

Size + junk denylist → secrets scan (gitleaks) → taxonomy check. Atomic reject before any DB transaction opens. No secrets, ever.
